## 1. 这是什么、做到哪了

## 4. 关键口径（答辩/文档必须一致）

- **旁路不改写业务流量**：脱敏对象是「可审计副本 + 告警」，在线阻断/改写只是可选演示。
- **三级协同按需升级**：L1 全量（微秒级）→ L2 只处理命中样本（语义复核/压误报）→ L3 只解释少量疑难（默认**只解释、不覆盖级别**，封顶 L2）。
- **L1 17 条规则 + 4 条自由文本规则 + 地名库 + 三级敏感词表（Aho-Corasick，66 词）+ 编码载荷解码复核**（base64/percent/hex，两层嵌套）。
- **隐私增强导出**：DP 只作用于**导出统计**（Laplace 计数），行级明细仍靠四级脱敏；`l-多样性`给出违规分组。
- **原文不入库**：库里只有脱敏副本、区间与哈希；审计链 SHA-256 + HMAC，`/audit/verify` 可校验。
- **L3 训练侧**：LoRA 把裁判单任务 60%→76.2%，但接管道会拉低端到端（100%→91.2%），所以默认只解释——这是实测结论，不是没做完。

## 6. 环境坑（Windows 专属，踩过的）

1. **pytest 必须 `cd server`** 再跑（`python -m pytest -o addopts="" -q`），否则包路径/基准脚本找不到。
2. **PowerShell 5.1 跑 `.ps1` 要 UTF-8 with BOM**，否则中文乱码报「缺少 }」；`.cmd` 包装保持纯 ASCII；here-string 会吃反引号、也不支持 heredoc → 复杂补丁写成 `.py` 文件再执行更稳。
3. **github.com DNS 时好时坏**（实测被指向 127.0.0.1）：直连 `git push` 失败时，用本地 CONNECT 代理（`HTTPS_PROXY=http://127.0.0.1:8888`）+ `git -c http.version=HTTP/1.1 push`。
4. **exe onefile** 需 `runtime_tmpdir=".flowmask-tmp"`（相对工作目录）；桌面快捷方式经 `cmd.exe` → `start_flowmask.cmd` 中转（`.lnk` 在受限会话里可能激活不了）。
5. **ONNX 导出**：roberta 的 int8 量化必须 `per_channel=True`；推理前 tokenizer 要 `no_padding()` + 用 `attention_mask`。
6. **评测报告生成顺序**：先主集、后压力集；压力集跑完会覆盖 `docs/评测报告.md`，需要 `git checkout --` 恢复或用 `evaluate --report` 重生成。
