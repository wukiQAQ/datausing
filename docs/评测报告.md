## 6. 口径与局限（如实说明）

- 评测集为**自建标注集**（`eval/dataset.jsonl`，人工标注 + 校验位生成的真实格式号码），标签遵循需求 v2 的分级策略；指标反映「实现与策略的一致性」与「困难样本判别力」，不等同于公开数据集上的绝对水平。
- 默认只跑 **L1（规则 + 校验算法）**：不需要模型、任何机器可复现；L2/L3 的增益用 `--compare-l2`（内置 mock 后端）或 `--enable-l2`（指向真实 L2 服务）单独对比。
- 评测集里刻意放了一批「文档/测试示例中的形似号码」（标注 SAFE）：真实业务里它们不需要脱敏，但纯规则会被形状骗到——这正是 L2 语义复核的增益来源。
- 目前语料以中文业务文本/JSON/CSV/SQL 为主，样本量适中；扫描件 PDF、图片里的文字不在本轮范围。
- 下一步：引入公开/半公开语料（政务公开数据、合成语料）扩充到千条级，并补 L2/L3 对照实验与消融。
