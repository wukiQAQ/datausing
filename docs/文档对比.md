# 批量文档对比

仅增量增强 `web/src/views/BatchView.vue`；独立组件 `DocumentComparison.vue` / `DocumentPane.vue` 复用 Element Plus、现有 CSS 变量和下载 helper，不增加依赖。

## 数据协议与一致性

批量上传 `/api/v1/tasks/batch` 复用即时检测的 HttpOnly、SameSite=strict 会话 Cookie（HTTPS 下 secure）。所有 API 仍经过既有 Bearer 校验；快照 owner 是 Cookie 与 Authorization 的联合指纹，不能凭任务 ID 跨会话读取原文。此项目没有用户账号/RBAC，这里沿用现有会话隔离，不把可自报的操作人头当权限依据。

后台任务检测一次，经过既有 `protected_text` 安全边界生成真实副本，然后把同一 document/report 短时放入现有 SnapshotStore，键为 `task:{id}`；不新增原文数据库列或磁盘文件。TTL 默认 300 秒、共用 32 个/32 MiB 预算和定时清理器。内存不足不阻断原有任务，对比显示快照不可用。

- `GET /api/v1/tasks/{id}/comparison`：先检查任务完成，再校验 owner、密钥版本、策略版本和快照有效期。响应 `Cache-Control: no-store` / `Pragma: no-cache`。
- 返回 `filename/status/coverage/hits/representation/offset_unit/segments`，每段有 `path/original/masked/changes`。`changes` 为码点半开区间 `start/end/masked_start/masked_end`，附类别、实际检测级别、实际策略及处理状态。
- 映射由共享脱敏算子在生成替换值时产生，不搜索字符串，不在前端模拟脱敏。再次生成的结果必须与任务快照中的副本一致，否则拒绝输出。对重复值、重叠命中、emoji、非等长替换均按实际位置处理。没有精确证据时沿用整段屏蔽，并明确标注。
- `GET /api/v1/tasks/{id}/comparison/download`：同样校验权限，直接按片段顺序用换行连接右侧副本，输出 UTF-8 txt。与工作台一致；不更改原 `/export?format=jsonl`（表格中称“明细”）行为。

前端 fetch 禁用缓存且可取消。弹窗关闭或路由卸载时立即 abort 请求、清除行模型和选中信息；不写原文到 localStorage、日志或遥测。服务端快照继续受短 TTL 管理，以支持重新打开，不声称能强制擦除 JS/进程堆内存。Vue 文本插值防止原文被作为 HTML 执行。

## 交互和性能

90vw × 86vh 弹窗复用 Element Plus 焦点管理、Escape 和滚动锁定。宽度 760px 以下自动单栏，可切换原文/脱敏；窄屏时下拉归一为「仅查看原文」，拉宽自动恢复双栏。行号、等宽字体、横向滚动/自动换行、轻红/浅蓝字符高亮。点击任一侧映射到另一侧，支持循环上一处/下一处；字段信息为绝对定位的小浮层，复用 `RiskIndicator` 显示实际级别。点击高亮只在对侧目标不可见/贴边时滚动，不会把当前阅读位置顶走；Escape 先收起展开的视图下拉，再按一次关闭弹窗。

每侧独立虚拟行，仅渲染视口及缓冲区。行高测量支持换行：未测量行按可视宽度与字符宽度（全角按 2 个半角）估算，定位后测量实际行高并最多两轮校正。滚动使用 requestAnimationFrame 合并；联动根据差异和片段行锚点插值，不按整份文档百分比定位。单栏/双栏切换保持两侧 pane 挂载，滚动位置与选中项不丢失；行查找、滚动锚点查找使用二分。

## 限制与异常

- 只支持本次新增批量上传保留的快照；历史任务、超过 5 分钟、进程重启、快照被淘汰时返回 410。缺权限 401/403，任务未完成/失败或策略/密钥变化 409，片段总字符数超过 1,000,000 返回 413。非批量任务不创建对比快照，同一入口返回 410（前端只在批量结果提供对比入口）。
- 对比顶部“命中数”统计全部检测命中（含低于结果最低级别的命中）；批表明细/统计按结果最低级别过滤，两者口径不同，界面已用 title 说明。
- 展示解析器实际参与检测的片段及片段内原始换行，不是原始文件的二进制或版式预览；解析器已有的截断/抽取限制仍适用，不显示未检测内容。PDF 不在浏览器重建页面。
- 新脱敏文件为 txt，不承诺原格式 DOCX/XLSX/JSON 排版还原；现有 JSONL 审计明细导出不受影响。
- 批量任务现有实际策略为至少 partial、高危 block；泛化/化名/加密等不被伪造为批量可选策略。共享映射算子测试覆盖已有六种策略，未来业务增加策略时可复用映射。
- 无敏感信息时显示无差异；推理降级以“检测覆盖不完整”提示。加载失败仅显示固定错误说明，避免把错误体中的输入反射到界面。
- 1,000,000 字符上限内极端“全换行”文档（约 100 万行）在前端建行模型仍有较高内存开销；服务端按字符总数拒绝超限文件。每帧虚拟行几何为 O(总行数)，十万行量级滚动可用，百万行极端文档非目标场景。
- 虚拟滚动下把选中高亮滚出视口会卸载该行节点，键盘焦点回到文档容器；可通过上一处/下一处重新定位，暂无单独“回到选中”按钮。点击跨行/整段高亮的后段时，对侧联动按该差异起始行定位。
- 逐字符映射依赖服务端 changes 有序不重叠；前端已做排序/裁剪防御。单栏视图下同步滚动置灰（无第二栏可同步）。
