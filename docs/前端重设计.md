# FlowMask Precision Workspace

## 审查结论

本次目标为 `web/`，不是旁边旧版 MeTD 的 `client/`。正式界面为 Vue 3.5、Vite 5、JavaScript、Element Plus 2、ECharts 5；无 Vue Router/Pinia，页面由 hash 与组件局部状态管理。FastAPI 在 `/app/` 托管产物，桌面入口 `server/desktop.py` 启动本机服务并以 Edge/Chrome app 模式打开；不是 Tauri 容器。保留后端、Python 打包和 API 数据契约。

| 页面 | 数据交互与保留能力 |
| --- | --- |
| 实时检测 | `/detect` JSON、`/detect/file` multipart；自动文本/JSON/CSV/SQL；四级分级、区间、模型链、降级、NER；`/scenarios`、`/mask-strategies`；POST 文件导出、密文还原、助手方案 |
| 批量检测 | `/tasks/batch` 多文件提交、逐任务轮询、统计、详情、鉴权 JSONL 导出；单文件失败隔离 |
| 流量导入 | `/traffic/formats`、sample、import，任务轮询、CSV/JSONL 导出；live 列表/开始/停止/清理与告警 |
| 任务与审计 | 文本/文件建任务、任务与 findings 分页接口、四格式导出、ε/l 隐私增强导出；审计条目与验签/断链位置 |
| 统计 | `/stats` 级别/类别/直方图、`/assistant/advise` 仅聚合数字的风险研判 |
| 规则 | `/rules` 列表/新增/启停/删除；内置规则禁止删除，正则由服务端校验 |
| 动态脱敏 | `/dynamic/render` 真实授权视图、操作人审计、`/dynamic/policy` |
| 设置 | 助手 health/models、策略、场景与留存、FAQ；服务端配置只读 |
| 全局 | `/health`、按操作人的 `/preferences`；Bearer token 下载，主题持久化 |

没有发现需要用静态数据补齐的业务页。NER/OCR 依赖本机可选模型/依赖；L2/L3 的 health 字段只表示服务端配置，不能据此宣称模型在线。助手有 rules/ollama/degraded 真实来源。实时检测不落库，只有任务/授权访问等入口留审计，界面需明确区分。

原有问题：无导航分组/折叠；顶栏拥挤；参数平铺；黄色高亮；structured spans 被错误应用到整个输入；UTF-16 与 Python 字符偏移不一致；主题切换通过 key 重建页面；文件失败可能混淆上次结果与导出源；批量清空未清组件文件列表；各页硬编码浅色。

## 已定设计规范（不要重新讨论这些）

- 色彩：背景/侧栏/表面/浮层 `#0B0D10/#101318/#15191F/#1B2028`；边界 `#2A3039`；文字 `#EDF0F4/#9AA4B2`；强调 `#45D6C0`。浅色主题独立对比度值。
- 风险：L3 红、L2 橙、L1 蓝、SAFE 绿；标签同时显示文字。计数忠实使用 by_level（分段分类），总命中为 findings.hits 之和，不混淆两种口径。
- 字体：系统 UI + 微软雅黑；标题 24/面板 14/正文 13/辅助 12px；正文等宽只用于编辑器/数据。
- 间距 4/8/12/16/20/24/32；圆角 6/10/12；边界仅分隔工作区，无光晕/渐变。
- 侧栏三组八入口；工具栏只放紧凑服务状态、引擎配置、用户和主题。状态可刷新，失败明确提示。
- 输入、检测、对照、导出四步；高级选项使用 Reka UI Collapsible 渐进披露；Phosphor Vue 图标统一线宽；Element Plus 保留表格/弹窗/表单/Toast 等成熟交互。
- 原文与副本按服务端片段路径对齐；文件服务端不回传原文时明确说明，禁止将输入框原文错套文件 spans；大结果分页与固定高度滚动。
- 主题切换不能重建业务页；敏感输入不存 localStorage/日志；仅复制脱敏结果；清空需确认。
- 控件 hover 140ms；展开 200ms；尊重 reduced-motion；键盘 focus-visible；980/1280/1440/1920 桌面窗口保持业务入口。

## 实施与验证顺序

1. 设计 Token、共享原语与工作台外壳。
2. 实时检测输入/状态、风险摘要、同步对照、明细与所有已有导出/助手弹窗。
3. 批量、流量、任务、统计、规则、动态和设置的业务布局与统一组件迁移。
4. Node 单元测试、生产构建、现有 Python 测试；启动真实 FastAPI 与 Vite，用 Playwright 检查实际界面（本会话未提供 Browser 插件运行时）。实测结果见 HANDOFF.md。
